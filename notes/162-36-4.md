# [[162,36,4]] — periodic bivariate-bicycle on Z_9 x Z_9

## Direction & hypothesis

The bivariate-bicycle family (arXiv:2308.07915) commutes automatically over
Z_l x Z_m: any monomial choice yields a valid CSS code, so the family can be
swept exhaustively at small torus sizes. The 2026-07-16 weight-6 sweep
targeted the `unrestricted / weight-6` cell of the board, which was dominated
by high-distance codes ([[360,12,24]], eff 19.2) but thin in high-rate points:
the goal was a distinct Pareto point at k/n > 0.2 rather than another
distance-first entry.

## What was searched

Periodic bivariate-bicycle enumeration (kit `bb.build_bb`) over Z_l x Z_m,
weight-3 monomials per side (max check weight 6), n = 2·l·m up to 162, screened
at 400 RIS trials with `min_k = 4`, `min_d = 4` (sweep metadata: sampler
`enumerate`, seed 7, 2026-07-16). The sweep script was not retained; the
survivor's parameters are recorded in provenance and can be reproduced from
the explicit construction below.

## Evidence trail

- Parameters (recomputed from H_X, H_Z): n = 162, k = 36, max check weight 6,
  CSS commutation holds.
- Screen (2026-07-16): d <= 4 at 400 trials.
- Fresh witnesses (2026-08-15, `make_submission`, trials = 8000, seed 7):
  weight-4 on each side, verified against the verifier's witness criteria
  (in the opposite check kernel, outside its own rowspace).
- Trusted gate `verify/validate_candidate.py` (2026-08-15, fresh seed): passed,
  refutation clean at 8000 RIS trials, `dominated_by: []`, on the
  weight-6 / unrestricted Pareto frontier as of the 302-entry board.
- Score kd^2/n = 36·16/162 = 3.556.

Tier: `d <= 4` (witness-backed upper bound; not server-certified exact). The
same witnesses survived a fresh gating seed when the code was re-validated.

## Dead ends

Three siblings from the same sweep sit below the current frontier and were not
submitted:

- [[162,12,8]] — dominated by [[144,12,12]], [[144,16,8]], [[128,12,8]]
  (all smaller or equal n with higher or equal d at k=12).
- [[168,18,6]] — dominated by [[144,24,6]] (smaller n, higher k, same d).
- [[168,6,12]] — dominated by six weight-6 entries including [[98,6,12]]
  and [[140,6,14]].

Only [[162,36,4]] survived the Pareto check; the pattern is the usual one for
periodic BB at this size: k and d trade off sharply, and only the high-k /
low-d corner had headroom.

## Reproduction

```python
from research.kit.bb import build_bb
from research.kit.css import compute_k, verify_css

HX, HZ = build_bb(9, 9,
                  A_terms=[(0, 0), (0, 3), (3, 3)],
                  B_terms=[(0, 0), (3, 0), (3, 3)])
assert verify_css(HX, HZ)
assert compute_k(HX, HZ) == 36
```

`n = 2 * 9 * 9 = 162`. Package the matrices through the kit's submission
functions, preserving the witnesses, then run the trusted gate on the resulting
document with `verify/validate_candidate.py`.
