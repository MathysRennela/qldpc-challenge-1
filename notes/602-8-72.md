# [[602,8,72]] — 2BGA on the metacyclic group Z_43 x| Z_7

## Direction & hypothesis

Target the weight-8 × unrestricted cell at n ≈ 600. The board's weight-8
frontier there is dominated by structured non-abelian 2BGA codes (e.g.
[[310,16,23]] on Z_31 x| Z_5), so I aimed at the same family — two-block
group-algebra codes over non-abelian metacyclic groups — which is less mined
than the abelian bivariate-bicycle family and can reach high k and high d at
moderate blocklength.

## What was searched

A targeted sweep over high-k metacyclic groups Z_p x| Z_q (order ≤ 350, so
n = 2·order ≤ 700), with random supports of weight 3–5 per side. Groups were
pre-screened by measuring the best k reachable over 400 random supports each;
the high-k groups (Z_31 x| Z_5, Z_37 x| Z_3, Z_43 x| Z_7, Z_29 x| Z_7,
Z_17 x| Z_6) were then searched for codes with k ≥ 8, max check weight ≤ 8,
and a distinct (n,k) pair. Candidates were screened with the gf2_fast RIS
accelerator (~2k–20k trials) and kept only if they strictly dominated the
weight-8 × unrestricted frontier.

The first advancing hit was on Z_43 x| Z_7 (order 301, r = 4) with supports
a = [101, 298, 76, 82, 215], b = [165, 152, 299].

## Evidence trail

Distance is a witness-backed upper bound. The submission's witness search
found d_X ≤ 82 and d_Z ≤ 72, so d ≤ 72. Both witnesses were validated against
the verifier's own criteria (in the kernel of the opposite checks, outside the
rowspace of their own checks). The trusted gate
(`verify/validate_candidate.py`) passed the code: no lighter logical was found
in an 8000-trial RIS refutation, and it is not dominated by any weight-8 ×
unrestricted board entry (`board_advancing: true`, `dominated_by: []`).

## Dead ends

Random 2BGA search over non-abelian groups overwhelmingly produces k = 0 codes
(≈ 143/3000 samples), and high-k codes (k ≥ 14) are rare (≈ 1/3000). Most
candidates that clear the k ≥ 8 screen are dominated by the dense weight-8
frontier. The distance is still drifting down under deeper search (a 50k-trial
measurement read d ≤ 70–78), so the true distance may be lower than 72; even
at d ≈ 25+ the code remains board-advancing in this cell, since no weight-8
code at n ≤ 602 has d ≥ 25.

## Tools

Found by an agent-driven search (model DeepSeek V4 Flash 0731) using the repo's
`research/kit` constructors (`group_algebra.metacyclic`, `build_2bga`) and the
`gf2_fast` RIS accelerator. Witnesses re-validated with the kit's python GF(2)
stack and the code run through `verify/validate_candidate.py` during staging.

## Reproduction

Z_43 x| Z_7 = `research/kit/group_algebra.metacyclic(43, 7, 4)`. Build the 2BGA
via `build_2bga(mul, a, b)` with a = [101, 298, 76, 82, 215],
b = [165, 152, 299] (element indices) to obtain [[602,8,72]].
