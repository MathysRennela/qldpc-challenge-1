# [[112,8,5]] trivariate bicycle (multivariate-bicycle family)

Primary reference: [arXiv:2406.19151](https://arxiv.org/abs/2406.19151)
(Voss, Sim, Haug, Bharti), SM Table 2, weight-4 row.

## Direction & hypothesis

The weight-4 × unrestricted cell on the board has no entry with k >= 8 and
d >= 5 at n <= 112 (the nearest high-k weight-4 neighbors are low-distance
[[101,5,5]] and [[169,10,3]]). A trivariate-bicycle code with two monomials
per side keeps check weight 4 while lifting k via the Z_l x Z_m torus, so
the paper's [[112,8,5]] row was the natural candidate for that point.

## What was searched

Reproduction of the published row (l, m) = (7, 8), A = z^2 + z^6,
B = x + x^6.

**The construction** (the paper's R3' reduction, which is all a TB code is):

- Variables are x = S_l ⊗ I_m, y = I_l ⊗ S_m, z = S_l ⊗ S_m = x·y (S_n the
  size-n cyclic shift), over Z_l x Z_m. The third variable is *not*
  independent: z^i = x^i y^i, so the exponent pair of a monomial
  x^a y^b z^c on the (x, y) torus is (a + c mod l, b + c mod m).
- This maps every TB code to an ordinary periodic BB code: build the
  l·m × l·m permutation sums A and B from the translated exponent pairs,
  then
      H_X = [ A | B ],   H_Z = [ B^T | A^T ],   n = 2·l·m.
  CSS commutation is automatic (abelian group algebra; Aᵢ and Bⱼ are
  circulants over the same torus). The kit's `bb.build_bb` produces exactly
  this matrix from (l, m, exponent-pair lists), so rebuilding a TB row only
  needs the translation above applied to the paper's monomials.

Applied to this row: z^2 → (2 mod 7, 2 mod 8) = (2, 2), z^6 → (6, 6),
x → (1, 0), x^6 → (6, 0), giving
A = {(2,2), (6,6)}, B = {(1,0), (6,0)} on Z_7 × Z_8.

## Evidence trail

Building H_X, H_Z from those exponent pairs yields n = 112, k = 8 (kit
`compute_k`; the paper's Table 2 also reports k = 8). CSS ✓. Independent
witness search (surrogate, 8000 trials per side, seed 0/1): X logical
weight 5, Z logical weight 5, each verified against the verifier's
criteria. d = 5 is a witness-backed upper bound, `confidence: upper_bound`.
Gate result on the staged doc: passed: true, label "advances the weight-4
x unrestricted board".

## Dead ends

This cell also contains the paper's [[144,2,12]] row (k=2) and the toric
baseline [[64,2,8]]; within the cell they solve a different design point
(low k, high d) vs this entry (high k at fixed weight). The paper's
weight-6 family (e.g. [[30,6,4]]) does not compete here: weight 6 falls
outside the weight-4 cell by definition.
