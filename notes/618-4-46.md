# [[618,4,46]] — weight-6 bivariate bicycle over Z_3 x Z_103

## Direction & hypothesis

Target cell: `unrestricted / weight-6`. Under `k >= 4` and check weight at most
6, no entry on the board had ever exceeded `d = 38` (`codes/618-4-38.json`,
then `codes/564-4-36.json` at 36) at any n. A weight-6 code at
`n = 618, k = 4, d = 46` moves that corner by eight in d and, because it sits
at the same n and k as `codes/618-4-38.json`, also beats that entry head to
head. Bivariate bicycle codes give weight 6 for free when `|A| = |B| = 3`, so
the sweep searched small group orders against the divisibility condition of
arXiv:2502.17052v4; `n = 618 = 2 * 3 * 103` is one such order.

## What was searched

Bivariate bicycle codes `H_X = [C_A | C_B]`, `H_Z = [C_B^T | C_A^T]` over
`Z_p x Z_q` with `|A| = |B| = 3`, so every check has weight 6 and
`n = 2 * p * q`. Candidates were kept only when the group order satisfied the
divisibility condition of arXiv:2502.17052v4. The sweep's run count and seeds
were not preserved with the candidate, so no sweep size is claimed here.
Screening was on `(n, k, d, w)`: anything already on the board's weight-6
frontier at those parameters was dropped.

- `verify/qldpc_verify.py codes/618-4-46.json` returns `ok: true`, all 14
  checks. Computed `rank H_X = rank H_Z = 307`, so
  `k = 618 - 307 - 307 = 4`; `H_X H_Z^T = 0`; Tanner graph connected with
  girth 6 on both sides; max check weight 6; weight class `weight-6`,
  locality class `unrestricted`.
- `verify/validate_candidate.py` on the submitted bytes returned
  `passed: true` (seed 290122940): `refuted: false` after 8000 RIS trials per
  side, `exact_duplicate_of: null`, `wl_equivalent_of: null`,
  `board_advancing: true`, `dominated_by: []`. The `qldpc_verify.py` pass ran
  its own refutation independently (seed 1567472090) and also found no lighter
  logical.
- **The distance was corrected before submission.** The campaign claimed
  `d = 52`. An earlier validator run refuted that with a weight-46 Z-side
  logical, and a later run found a weight-50 logical; both were verified to
  commute with the X checks and to lie outside the row space of the Z checks.
  The weight-46 witness is the lightest known and is the one shipped. The X
  side witness is weight 62.
- **The claim is a witness-backed upper bound, not a certificate.** Both sides
  carry `confidence: upper_bound`, so this states `d <= 46`; nothing here
  proves that no lighter logical exists.

## Dead ends

The claimed `d = 52` was the dead end: refuted twice, once at weight 46 and
once at weight 50. Correcting the claim to the lightest known witness is what
makes the code submittable. Siblings from the same sweep: `[[574,6,38]]`
shipped unchanged in its own PR, `[[490,6,32]]` ships corrected in another,
and `[[450,4,38]]` (which would correct to `[[450,4,30]]`) is not submitted
because it no longer dominates anything once corrected.

## Reproduction

`G = Z_3 x Z_103`, with group element `(i, j)` indexed as `103 * i + j`, so
`|G| = 309` and `n = 2 * |G| = 618`. With `C_S` the `309 x 309` matrix
`(C_S)_{g,h} = 1` iff `h - g` lies in `S`:

- `A = {(0,0), (1,29), (2,15)}`
- `B = {(0,0), (1,35), (2,46)}`
- `H_X = [C_A | C_B]`, `H_Z = [C_B^T | C_A^T]`

Building those two matrices from the supports above reproduces the check lists
checked in at `codes/618-4-46.json`.
