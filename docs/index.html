qLDPC Challenge

GitHub

Find better quantum LDPC codes.

The codes here are the best we currently know of in each track: the bar to beat. The challenge is to find better ones: submit a code that uses fewer physical qubits, encodes more logical qubits, or reaches a higher distance than the frontier, and once CI verifies it, it joins the board under your name. It is a challenge, not a catalog.
