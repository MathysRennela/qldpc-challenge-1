best operational efficiency
Operational efficiency kd²/n — the Bravyi–Poulin–Terhal ratio, normalized so the surface code sits at 1. Bounded for 2D-local and bounded-weight codes; grows with n for high-rate codes, so it is compared within tracks, not as a global record.
Geometric efficiency g = 4kd²/(nρ²r⁴) — the same ratio priced by the layout the code ships with, normalized so the planar surface code scores exactly 1. Computed only for codes with a verifier-accepted layout; an upper-bound distance makes g an upper bound, and the headline requires d ≥ 3.
n physical qubits · k logical qubits · d code distance (smallest undetectable error) · w max check weight · r interaction radius: the largest check diameter in the layout, in units of the minimum qubit spacing · ρ qubit layers per site (2 = flip-chip bilayer; charged as ρ² so stacking must earn its density)
